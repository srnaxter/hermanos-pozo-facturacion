# Hermanos Pozo · Facturación

Web estática preparada para desplegarse en Netlify o GitHub Pages. No necesita servidor ni base de datos.

## Acceso de demostración

- Usuario: `admin`
- Contraseña: `HermanosPozo2026!`

El acceso es un bloqueo visual en el navegador, adecuado para una demo o uso interno sencillo. Para proteger datos reales habría que conectar el formulario a un servicio de autenticación y backend.

## Publicar en Netlify

1. Sube estos archivos a un repositorio de GitHub.
2. En Netlify selecciona **Add new site → Import an existing project**.
3. Elige el repositorio y deja el comando de build vacío; la carpeta de publicación es la raíz (`.`).
